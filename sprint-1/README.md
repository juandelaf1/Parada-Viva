# Sprint 1: Red de comercios MVP

**Objetivo:** Validar que caravanistas concienciados usan la app para encontrar
comercios y registran su visita mediante QR, y que los comercios ven valor en
participar.

**Duración:** 4 semanas

## Issues

| ID | Título | Prioridad | Esfuerzo |
|----|--------|-----------|----------|
| US-001 | Mapa con comercios adheridos | P0 | 3 días |
| US-002 | Check-in vía QR | P0 | 3 días |
| US-003 | Valoración tras check-in | P0 | 2 días |
| US-004 | Alta de comercio (admin) | P0 | 2 días |
| US-005 | Registro de usuario con magic link | P0 | 1 día |
| US-006 | Perfil de usuario con historial | P1 | 2 días |
| US-007 | Landing page pública | P1 | 1 día |

## Definición de completado del sprint

- [ ] Un caravanista puede ver el mapa, localizar un comercio, escanear QR,
      dejar valoración
- [ ] Un comercio puede aparecer en el mapa y recibir visitas
- [ ] Las visitas quedan registradas (usuario, comercio, fecha, valoración)
- [ ] Todo funciona sin errores críticos
- [ ] Tests básicos pasan

## KPI de validación (post-sprint)

- 10 comercios dados de alta
- 30 check-ins realizados
- 80% de check-ins con valoración positiva (≥4 estrellas)
